# SL 课程机制：让数据决定何时转向现代打法

> 核验：2026-09-07。基于已完成 Long-ABC 的原始产物及下列论文。用户已批准按本方案实施；同起点探针和采样游标已实现，运行与验证记录见 [实施记录](sl-curriculum-probe-implementation-2026-09-07.md)。自动连续变权重仍须验证，不替换活跃训练。手工阶段预算仅作最后退路。

## 结论

问题应定义为：**在当前模型状态下，下一份计算投入哪种数据最有价值？** 现有停止规则回答的是“本阶段相对自己的历史 best 有没有改善”，没有测量“现在转 B/C 的收益”。即使 A 仍在改善，B/C 的边际收益也可能更高。只调整 patience，无法回答这个反事实问题。

建议保留 A/B/C 作为三种数据配方，先用**同起点、相同新增计算量的分支探针**测量目标域收益；确认测量有效后，再让该信号选择下一种配方，或缓慢调整混合比例。阶段长短由这些决策累积产生。无需先规定 A/B/C 各占多少步。

这不保证 C 一定胜出。真正让数据说话，也要允许“正确控制后，C 仍没有额外收益”这一结果。需要消除混杂后再判断，不能将本次 C 的结果直接解释为现代数据没有价值。

按阶段步数乘以文件采样比例粗算，2023–2024 数据暴露代理值约为 **63.65%**。这不是实际消费的决策样本统计：各局长度、过滤、重放和恢复都会影响比例。最终 finalist 的保留路径是 A 288 万步加 B 5 万步；被放弃的 A 尾部、B/C 后续计算也不能都算进其权重学习历史。

### C 有过一个尚未被确认的正信号

C 继承 B 的 50k 计数。其记录在累计 100k、即本阶段新增约 50k 时，相对继承的 B best：

| 指标，当前减 B best | 点估计 | 历史逐局配对 95% CI |
| --- | ---: | --- |
| 近期 policy loss，越低越好 | −0.000578 | [−0.001239, +0.000082] |
| 近期动作准确率，越高越好 | −0.000377 | [−0.000987, +0.000232] |
| 旧域 policy loss，越低越好 | +0.000651 | [−0.000179, +0.001481] |

近期 NLL 的点估计改善，但没有达到“置信界越过有意义改善阈值”的要求，其他护栏也未同时证明通过。**不能说 C 从未改善，也不能据此说 C 应当获胜。** 若真实效果和方差保持不变，只解决主指标的精度、仍以 0.0002 为阈值，粗略需要约 1,561 局而非 512 局；扩大验证不会自动解决准确率或旧域方向不利的问题。这个推算不包含多次选择修正，也不是保证获得显著结果。

C 后段并非只是误差条过宽，近期和旧域点估计均明显恶化；但期间验证/runtime 曾修复，仍需在同一冻结实现上重评保存权重。不能拿跨版本的跳变直接证明过拟合或训练永久受损。

## “共通原理 + 年代残差”如何变成可检验假设

这个建模直觉合理，但需要区分游戏动力学与模仿标签。即使规则相同，玩家策略变化也会改变遇到的状态分布 `p(s)` 和同状态下的动作分布 `p(a | s)`。SL 学的是牌谱动作；时间标签不会自动告诉网络哪些是共同原理，哪些是应该淡化的旧习惯。

同一个 NLL 既含可学的策略差异，也含信息不充分时的动作多样性、水平差异和标签噪声。“loss 高”不能直接解释成“现代知识尚未学会”；“年份新”也不是每个动作更优的保证。

实际 finalist 的 328,631 个验证决策中，256,470 个是打牌，占 78.04%；按其分组 NLL 还原，打牌贡献约 93.21% 的总 policy NLL。打牌包含复杂押退，不能把它们都当成简单基础动作；但总指标对不同决策类型的敏感度明显不同。某些关键切片很稀疏，例如南四脱四目标下的立直决策只有 78 个，且这些决策还不是 78 个独立游戏。按场景报告差异和统计精度，比凭一个总 loss 判断现代残差是否学完更有信息。

需要建立两类测量：

1. **现代目标表现**：固定未来时间窗，按月份、玩家事前水平与场景报告 policy NLL、准确率和关键动作表现。统一房间/规则/标签过滤、去重与增强。玩家水平只能使用行动前可获得的资质，不能按该局最终赢家或已实现分数挑样本。
2. **共通能力保留**：单列牌效率、听牌/安全判断、立直与副露、押退等场景；可精确计算的子问题用明确边界的算法目标，整体策略仍靠固定对手的 1v3。孤立进张数或安全度不能覆盖所有点况、收益和对手因素。

`old_regression_policy_loss` 应继续记录，但它首先衡量“像旧牌谱的程度”，不能等同于“保住底层能力”。当旧习惯被现代策略替代时，这个 loss 可能上升。**这是需要对照验证的护栏语义问题，本次没有直接删除或放宽现有护栏。** 也没有证据证明本次 C 完全是被旧域护栏误杀：它的主指标本来就未获得明确改善，准确率也未通过。

## 论文给出的可用思路及边界

| 原始研究 | 可以借鉴什么 | 不能直接照搬什么 |
| --- | --- | --- |
| [Graves 等，ICML 2017](https://proceedings.mlr.press/v70/graves17a.html) | 用学习进展作为非平稳 bandit 的奖励；区分训练样本自身变好与目标任务变好 | 单步梯度大小会偏爱高方差任务；目标增益有噪声，也可能低估早期基础学习 |
| [DoReMi，NeurIPS 2023](https://arxiv.org/abs/2305.10429) | 用相对参考模型的 excess loss 估计尚可学习的部分，避免只盯原始高 loss | 参考模型能力会影响残差；最难旧域可能被增权。它不直接优化“现代麻将更强”，也不能由此推导 C=98% |
| [DoGE，ICML 2024](https://proceedings.mlr.press/v235/fan24e.html) | 依据训练域梯度对目标域的帮助程度重加权，直接对应“老数据还能否帮助现代目标” | 原文主要在 proxy 上学习权重再用于 base model；附录 E 的动态分段并未普遍胜过静态平均，过细分段还明显变差。不能把快速在线变权重说成已证明更优 |
| [Skill-It，NeurIPS 2023](https://papers.nips.cc/paper_files/paper/2023/hash/70b8505ac79e3e131756f793cd80eb8d-Abstract-Conference.html) | 通过短训练估计技能间迁移关系，把“基础帮助进阶”的假设测成矩阵 | 年份划分未必就是技能划分；学习图、重复探针也消耗计算，不能把探针成本忽略 |
| [Ren 等，ICML 2018](https://proceedings.mlr.press/v80/ren18a.html) | 使用目标验证集的梯度决定训练样本权重，说明数据选择可以由目标反馈驱动 | 有效性依赖有代表性的目标集；用于更新采样器的数据已参与优化，不能再当独立 test |

这些是方法上的依据，**没有一篇证明该 Mahjong 网络的最佳数据比例或课程长度**。较新的 [Data Mixing Agent](https://arxiv.org/abs/2507.15640) 用大量混合轨迹训练控制器；我们缺少这类轨迹，不建议当前先承担训练另一个 RL 控制器的成本。

长期训练是否降低后续可塑性，也有研究依据。[Dohare 等，Nature 2024](https://www.nature.com/articles/s41586-024-07711-7) 在连续视觉任务和 RL 中测到学习新任务的能力下降；[Lyle 等，2024](https://arxiv.org/abs/2402.18762) 分析了多种独立机制。它们支持把“晚转更难适应”列为假设，不能诊断本模型已经发生这种问题。验证应从不同 A 时点出发，在相同新数据、辅助目标和 optimizer 条件下比较后续学习曲线；在本次目标漂移尚未排除前，不应直接给主网做神经元重置等干预。

## 推荐实施路径

### 1. 先恢复干净的比较条件

- 从明确的 A anchor 开新分支，使用修复后的同一辅助配方和 ramp 时钟。把 A/B/C anchor 的 step 0 都在同一冻结 runtime、同一验证游戏上重新计算。
- B/C 使用完整符合条件的近期域，或可追踪的不放回轮换覆盖；先固定比例，只改变覆盖，隔离固定 12 万/8 万池的影响。记录各年份实际消费的决策样本、独立游戏和重复率，不能只记配置比例。
- 同一比较中固定主 optimizer/scaler 初始化策略、LR 与 warmup。重升 LR 是否有用另做匹配对照；不能同时扩大池、改变辅助权重和重升 LR，再把结果都归因于课程。
- 当前 2025/2026 验证牌谱继续遵守原 split；若要引入更近期训练数据，先建立新的时间隔离划分和 provenance，不能挪用后继续声称旧验证独立。

### 2. 让 A/B/C 从同一状态竞争训练机会

在一个共同 checkpoint 上复制模型、optimizer、scaler、主 LR 状态和辅助时钟。三个探针分别使用 A、B、C 配方，其他设置一致，消耗相同新增成功 optimizer updates/决策样本。它们可以串行跑，设备并行不是方案成立的条件。

对每个配方 `d` 测量：

`G_d(H) = [L_target(parent) - L_target(after d, H)] / 新增计算量`

保留逐局配对差异及护栏。真正要比较的是 `G_B - G_A`、`G_C - G_A`，而不是只看 `G_A > 0`。如果 B/C 的收益可靠地超过继续 A，就让下一段计算转向它，即使 A 尚未平台。A 提供共通知识的好处会体现在其对目标域的实际帮助里，而不需要事先指定学习老数据的总时长。

探针只在预声明的观测点比较，跨训练种子确认排序；未决时优先增加独立验证精度，或把**竞争双方**的观测跨度一起扩大，不能只延长当前 A。探针长度是测量分辨率，不是整阶段预算。

防止短视必须作为准入条件：在两个以上观测跨度检查排序，并对有延迟收益可能的路线比较 `A→C` 与 `C→C` 的等计算两段路径。如果短跨度总把后续更好的路线淘汰，就不能接入贪心自动切换。保留探索机会，不因为一次低收益永久丢弃旧域或某个现代场景。所有探针成本计入整体训练成本。

“所有已试配方在当前 LR/跨度没有有效收益”只支持停止这组候选、或进入 LR/覆盖诊断；不能宣称达到网络全局上限。证据不足时输出 `inconclusive`，也不能把它改称收敛。

### 3. 验证通过后，再把离散选择变成缓慢变权重

可用 DoGE 风格的梯度信号减少真实分支训练成本。对于实际 optimizer 将做的更新 `Δθ_d`，估计目标收益 `−∇L_target · Δθ_d`。Adam 的动量、预条件和辅助梯度都应计入，不能仅拿两个原始梯度的 cosine 当真实收益。

用平滑后的收益调整各域权重，限制每次权重变化，并保留探索；通过旧能力诊断调整 replay。定期与真实短程对照校准，失配就回到离散探针。A/B/C 可以继续作为三种候选配方，也可以逐渐演变为一个连续混合日程；最终比例可以不是 60/90/98，阶段可以回访。

这一步的可接受结果包括稳定权重。DoGE 的负面结果提示：动态控制增加的噪声可能抵消收益，必须保留学得的静态混合比例作为基线，不能先认定越自适应越好。

### 4. 选择尺子必须独立于调度器

划分为用于采样反馈的 `controller-dev`、用于有限候选比较的 `selection-dev`、最终锁定后才打开的 `sealed-test`。用于梯度对齐的数据属于元优化数据。反复复用同一 512 局、每次看普通 95% CI，不能得到整个自动搜索仍有 95% 保证；应预声明确认点和多重比较规则，或使用适用假设经过验证的序贯方法。

主目标仍是最终强度。近期 policy loss 是便宜代理，正式 1v3 才能决定模型是否更强；总 NLL、近期准确率和细分攻防指标不应随看到的结果临时改权重。对于“现代适应带来旧域模仿 loss 上升”的候选，先列为诊断分支，依预声明的能力/对战标准验证，不绕过现有发布标准。

## 决策与退路

确定需要做的是修复辅助目标、统一比较输入、补实际采样覆盖统计，并测量“继续与转段”的差异。**我推荐先实现和验证同起点的 A/B/C 探针，然后再决定是否采用连续混合控制器。** 目前证据不足以替用户决定最佳 LR、永久放宽旧域护栏、或直接投入全量新课程长训。

只有在探针排序不能复现、目标信号不能预测独立强度、或控制成本明显抵消收益时，才回到手工预算。届时也应依据干净重评后的历史曲线给出一个小范围候选，并在端到端相同总计算量下比较；本次受目标和验证变化影响的曲线只能用于提出候选，不能直接作为最佳预算的答案。
